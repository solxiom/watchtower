# Independent Review — SRC-EXP-03

Status: **Required before a host route may enter comparative evaluation**

The independent reviewer must:

1. verify original/fixture repository identities, clean tracked status,
   no-hardlink isolation, source views, canary differences, and ownership;
2. reconstruct the installed-host inventory and prove the candidate set was
   frozen before any model call;
3. verify eligibility/ineligibility without exposing secret configuration;
4. canonicalize every approved schema/contract and exact outbound model tool
   set, recomputing bytes/digests;
5. correlate model request, structural tool invocation, result bytes, positive
   canary answer, and negative-view direct check;
6. prove route separation, sequential execution, fresh contexts, call limits,
   no native fallback, and no result-driven retry;
7. reconstruct cache/config/source-view writes, network behavior, processes,
   listeners, timeouts, tokens, schema/result bytes, and cleanup targets; and
8. confirm no provider/dependency install, project/global mutation, T1–T7
   call, product edit, or implementation occurred.

Immediate route rejection applies to absent outbound tools, zero correlated
structural calls, guessed answers, source-view/global/original writes, hidden
fallback, source leakage, or unbounded behavior. Missing exact outbound schema
evidence is `RESEARCH_BLOCKED`, not readiness.

The reviewer may reproduce safe read-only inventory/hash calculations and
non-model direct checks but may not install, configure, issue model calls, or
repair a route.

Return exactly:

- `ACCEPT_ROUTE_READY_EVIDENCE` with exact route/capability scope;
- `NO_ELIGIBLE_ROUTE` when the frozen inventory proves the empty candidate set;
- `REJECT_ROUTES` with numbered findings; or
- `RESEARCH_BLOCKED` with missing evidence.

Write only `.local/source-intelligence-experiment/SRC-EXP-03-review.md`, owned
by `kavan` mode `0600`. Do not amend specs, clean fixtures, or commit.
