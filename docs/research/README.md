# Watchtower Research Archive

This directory preserves rejected or inconclusive product research. Documents
here are historical evidence, not normative specifications, roadmap promises,
implementation authorization, or active experiment instructions.

## Source indexing decision

Watchtower will not build, operate, broker, cache, or expose repository source
indexes. Authorized agent hosts may use their own source-reading, search, LSP,
or retrieval capabilities, but that state remains outside Watchtower authority.

The archived design and experiment protocols are retained at:

- [Rejected source-intelligence draft](source-intelligence-rejected.md)
- [Source-intelligence evaluation history](source-intelligence-evaluation/)

The decision followed repeated inability to obtain accepted quality/cost
evidence, provider/host integration failures, cache writes outside declared
boundaries, and growing scope disproportionate to demonstrated product value.
